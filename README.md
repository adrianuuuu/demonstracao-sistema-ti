# 🚀 Sistema de Gestão de Chamados e Inventário de TI

Fala devs! 👨‍💻🌐  

Este repositório apresenta a **versão demonstrativa (MVP)** de um projeto que desenvolvi com foco em resolver problemas reais do dia a dia na área de TI: um **Sistema de Gestão de Chamados e Inventário de TI**.

O sistema foi pensado para ambientes corporativos que precisam de **organização, controle e agilidade no suporte técnico**, centralizando informações e melhorando a tomada de decisão.

⚠️ **Importante:**  
Este repositório contém apenas a versão **demonstrativa (frontend + mock)**.  
A versão real do projeto (em produção) possui backend completo, autenticação e banco de dados estruturado.

---

# 💡 Sobre o Projeto

Aplicação web completa para:

- Gerenciamento de chamados técnicos
- Controle de inventário de equipamentos
- Administração de usuários
- Monitoramento de atividades de suporte

Tudo centralizado em um único sistema.

---

# 🧩 Funcionalidades

- 📌 Abertura e acompanhamento de chamados
- 🔄 Controle de status (Aberto, Em Andamento, Resolvido)
- 📄 Visualização detalhada dos chamados
- 🧾 Sistema de anotações por chamado
- 🖥️ Gestão de inventário de equipamentos
- 🏢 Filtro por departamentos
- 📊 Dashboard com visão geral e indicadores
- 🔐 Sistema de autenticação (na versão real)
- 🌙 Interface com tema claro e escuro
- 📱 Layout responsivo (mobile + desktop)

# 🛠️ Tecnologias Utilizadas

- HTML5

## 🔹 Versão REAL (produção)

- Node.js
- Express
- Banco de dados relacional (SQLite / MySQL)
- JWT (autenticação e autorização)
- Middlewares de segurança
- API REST completa
- Controle de acesso por nível (admin / usuário)

- ❌ Falta de organização no atendimento de chamados
